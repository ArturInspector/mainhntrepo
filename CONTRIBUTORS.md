### How to Add Yourself

If you've contributed to NotABot, add yourself to this list:

1. Fork the repository
2. Add your entry to the table below (alphabetical by GitHub username)
3. Submit a pull request

**Format:**
```markdown
| [Your Name](https://github.com/username) | What you did | [@username](https://github.com/username) |
```
